## Run BOTH modules — updates Login + Upload Test Cases sheets
pytest tests/login/ tests/upload/ -v --headed -s

## Run ONLY login tests — updates Login sheet only
pytest tests/login/ -v --headed -s

## Run ONLY upload tests — updates Upload Test Cases sheet only
pytest tests/upload/ -v --headed -s

## Run a single test (example)
pytest tests/upload/test_upload.py::test_TC_UpLoad_08_minimum_size_file -v --headed -s

## ──────────────────────────────────────────────────────────────
## FLAG MEANINGS
## ──────────────────────────────────────────────────────────────

## --headed  → Open visible Chromium browser (default is headless)
## -s        → Show print() output (Excel Reporter summary, debug logs)
